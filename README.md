# AeroFit Treadmill Customer Profiling

An exploratory analysis of 180 customer records for the KP281, KP481, and KP781 treadmill models. The case study compares buyer profiles, estimates conditional purchase probabilities, and translates the observed patterns into marketing recommendations.

## Reproduce the analysis

Open the Jupyter notebook with the CSV in the repository root. The notebook uses pandas, NumPy, Matplotlib, and seaborn.
